## Data

**Source.** We use end-of-day S&P 500 index option chains from optionsDX, one file per month, with quotes captured at the 4:00 pm close. Each row gives, for one strike and expiry, the call and put bid, ask, last price, volume, implied volatility and Greeks (delta, gamma, vega, theta), together with the index level. We downloaded 2010–2023 (168 monthly files, 5.3 GB); the main analysis uses 2016–2020 as set out in the proposal. The paper used OptionMetrics for 2010–2019, so our replication tests the method on a different vendor and a later period that includes the 2020 crash.

**Cleaning and samples.** We apply the paper's filters: options with fewer than 14 days to expiry, with |delta| outside [0.05, 0.95], or with missing implied volatility or Greeks are removed. The vendor's Greeks are standard Black-Scholes values: recomputing delta from the vendor's own implied volatility reproduces it almost exactly. We build two datasets. The main dataset keeps every option with a positive bid (5,379,848 option-days with a next-day quote). The traded-only dataset keeps options with volume > 0 (1,941,559), which matches the paper's sample: for 2019 it has 396,275 observations, about 1,680 per trading day, against the paper's 433,271 (about 1,720 per day).

**Data problems.** The vendor files are missing 35 NYSE trading days over 2010–2023 (10 of them in 2016–2020), contain rows on days the exchange was closed (for example 5 December 2018), and in early 2010 show zero bids on every option for eight days. The original pairing code matched each day with the next day present in the file, which would have turned a missing day into a two-day move labelled as a one-day hedge. We rebuilt the pipeline on the NYSE trading calendar: an option on day t is paired only with the same contract on the true next trading day, and days without one are dropped. Two further defects were found when fitting the baselines: about 0.4% of puts carry an impossible vega (for example −1054 where the matching call shows 9.7), and six days in May 2019 have a corrupt implied-volatility surface. Both are removed in cleaning; the vega defect alone was depressing Hull-White's 2020 put gain from 16% to 4%. All affected dates are listed in `data/processed/data_quality.md`. The number of listed strikes also jumps in July 2018, which we note but do not adjust for.

**Hedging pairs and split.** Each observation pairs one option on day t with the same contract on day t+1, giving the change in the option's mid price (dV), the change in the index (dS), and the one-day hedging error dV − delta·dS. The split is chronological — train 2016–2018, validation 2019, test 2020 — because the same contract appears on consecutive days and a random split would leak information across days.

**Sanity check.** Fitting Hull and White's (2017) one-parameter correction delta* = λ·delta on 2016–2018 gives λ below 1 for calls and above 1 for puts, the same directions they report (0.91 and 1.08). On the 2020 test year this reduces hedging error by 16.0% for calls and 4.7% for puts; on the calm 2019 year the effect is close to zero (+1.4% and −1.1%). The full Hull-White correction, which sizes the adjustment by vega rather than delta, reaches 19% and 16%: for puts the crash effect is a volatility effect. The data therefore carries the effect the paper studies, and the gain of any correction depends strongly on the market regime.
