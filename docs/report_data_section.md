## Data

**Source.** We use end-of-day S&P 500 index option chains from optionsDX, one file per month, with quotes captured at the 4:00 pm close. Each row gives, for one strike and expiry, the call and put bid, ask, last price, volume, implied volatility and Greeks (delta, gamma, vega, theta), together with the index level. We downloaded 2010–2023 (168 monthly files, 5.3 GB); the main analysis uses 2016–2020 as set out in the proposal. The paper used OptionMetrics for 2010–2019, so our replication tests the method on a different vendor and a later period that includes the 2020 crash.

**Cleaning and samples.** We apply the paper's filters: options with fewer than 14 days to expiry, with |delta| outside [0.05, 0.95], or with missing implied volatility or Greeks are removed. The vendor's Greeks are standard Black-Scholes values: recomputing delta from the vendor's own implied volatility reproduces it almost exactly. We build two datasets. The main dataset keeps every option with a positive bid (5,427,323 option-days with a next-day quote). The traded-only dataset keeps options with volume > 0 (1,955,710), which matches the paper's sample: for 2019 it has 409,023 observations, about 1,690 per trading day, against the paper's 433,271 (about 1,720 per day).

**Data problems.** The vendor files are missing 35 NYSE trading days over 2010–2023 (10 of them in 2016–2020), contain rows on days the exchange was closed (for example 5 December 2018), and in early 2010 show zero bids on every option for eight days. The original pairing code matched each day with the next day present in the file, which would have turned a missing day into a two-day move labelled as a one-day hedge. We rebuilt the pipeline on the NYSE trading calendar: an option on day t is paired only with the same contract on the true next trading day, and days without one are dropped. All affected dates are listed in `data/processed/data_quality.md`. The number of listed strikes also jumps in July 2018, which we note but do not adjust for.

**Hedging pairs and split.** Each observation pairs one option on day t with the same contract on day t+1, giving the change in the option's mid price (dV), the change in the index (dS), and the one-day hedging error dV − delta·dS. The split is chronological — train 2016–2018, validation 2019, test 2020 — because the same contract appears on consecutive days and a random split would leak information across days.

**Sanity check.** Fitting Hull and White's (2017) one-parameter correction delta* = λ·delta on 2016–2018 gives λ = 0.94 for calls and 1.05 for puts, the same directions they report (0.91 and 1.08). On the 2020 test year this reduces hedging error by 15.9% for calls and 4.6% for puts; on the calm 2019 year it slightly increases it. The data therefore carries the effect the paper studies, and the gain of any correction depends strongly on the market regime.
